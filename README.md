# ResumeCheckTool

Objective: build a project using AWS AI services to gain hands-on experience and demonstrate expertise.

Goal: to create a web app that allows users to input a job description and upload their resumes to be scored with suggestions for improvement - "ResumeRadar"

# Run on React + Vite

## <a href="https://vitejs.dev/" target="_blank" rel="noreferrer"><img src="https://raw.githubusercontent.com/danielcranney/readme-generator/main/public/icons/skills/vite-colored.svg" width="36" height="36" alt="Vite" /></a> <a href="https://reactjs.org/" target="_blank" rel="noreferrer"><img src="https://raw.githubusercontent.com/danielcranney/readme-generator/main/public/icons/skills/react-colored.svg" width="36" height="36" alt="React" /></a>Step 1: Install node.js & npm

Vite requires Node.js version 18+ or 20+. However, some templates require a higher Node.js version to work, please upgrade if your package manager warns about it.
Select your operating system and architecture [here](https://nodejs.org/en/download/). Npm is included with Node.js.
In your project, you can install the vite CLI using:
```
npm install
npm run dev
```

or manually install vite

```
npm install -D vite
```
test that you have Node.js and npm correctly installed on your machine, you can type ```node --version``` and ```npm --version``` in a terminal or command prompt.


## Step 2: Download ZIP Code on your local machine
1. Navigate to the project link [here](https://github.com/hshittu17/ResumeCheckTool)
2. Click the green code <> button
3. Then, select Download ZIP

## Step 3: Run using React, supercharged with vite 
1. Unzip the file by double clicking the ZIP file
2. open a new terminal or command line prompt
3. navigate to where you saved the ZIP file using cd or equivalent
4. run ```npm start```
5. Then run the appropriate CLI command in your terminal:
```
npx vite
```

Click on the link to your local host link and open it in your browser. The index.html will be served on http://localhost:5173.
